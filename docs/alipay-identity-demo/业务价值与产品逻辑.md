# 业务价值与产品逻辑（合规加强版）

> 用于支付宝小程序「用户实名三要素」能力申请。  
> 已结合《旅馆业治安管理办法》《中华人民共和国治安管理处罚法》《中华人民共和国反恐怖主义法》进行论证。

---

## 1. 需要申请用户信息业务背景和理由

久窝朋赞会支付宝小程序服务于民宿、公寓、客栈等住宿业态旅客自助入住。旅客通过小程序办理入住实名认证后，方可使用蓝牙开锁等自助入住能力。该场景属于典型的**住宿业务身份查验与实名登记**场景，申请姓名、身份证号、手机号等实名信息，并非一般营销用途，而是履行法定义务、落实安全防范措施的必要技术手段。

### 1.1 法定义务：住宿必须查验并登记身份

依据《旅馆业治安管理办法》第六条：

> 旅馆接待旅客住宿必须登记。登记时，应当查验旅客的身份证件，按规定的项目如实登记。

据此，住宿经营者接待旅客时，依法应当查验身份证件并如实登记姓名、证件种类和号码等信息。小程序作为门店数字化入住通道，必须具备采集并核验旅客真实身份信息的能力，否则无法协助门店完成法定登记义务。

### 1.2 法律责任：未按规定登记将依法处罚

依据《中华人民共和国治安管理处罚法》第六十七条：

> 从事旅馆业经营活动不按规定登记住宿人员姓名、有效身份证件种类和号码等信息的，或者为身份不明、拒绝登记身份信息的人提供住宿服务的，对其直接负责的主管人员和其他直接责任人员处五百元以上一千元以下罚款；情节较轻的，处警告或者五百元以下罚款。  
> 实施前款行为，妨害反恐怖主义工作进行，违反《中华人民共和国反恐怖主义法》规定的，依照其规定处罚。

因此，若系统无法准确采集、核验旅客姓名与有效身份证件信息，门店将面临行政处罚风险；若进一步妨害反恐工作，还将依照反恐法从重处理。

### 1.3 反恐安全要求：身份不明不得提供住宿服务

依据《中华人民共和国反恐怖主义法》第二十一条：

> 电信、互联网、金融、住宿、长途客运、机动车租赁等业务经营者、服务提供者，应当对客户身份进行查验。对身份不明或者拒绝身份查验的，不得提供服务。

同法第八十六条第二款规定，住宿业务经营者、服务提供者未按规定对客户身份进行查验，或者对身份不明、拒绝身份查验的客户提供服务的，由主管部门处十万元以上五十万元以下罚款，并对其直接负责的主管人员和其他直接责任人员处十万元以下罚款。

据此，住宿场景不仅“应当查验身份”，而且对**身份不明或拒绝查验的客户不得提供服务**。久窝小程序申请支付宝实名三要素，正是为了在自助入住链路中落实“先查验、后服务”，避免向未核验身份的人员开放蓝牙开锁等高敏感能力。

### 1.4 申请信息与业务必要性

综上，申请支付宝实名三要素信息的理由是：

1. 落实《旅馆业治安管理办法》要求的住宿登记与身份查验义务；
2. 降低《治安管理处罚法》《反恐怖主义法》项下的合规处罚风险；
3. 在自助入住场景中确认“当前操作人”与“入住登记身份”一致，保障旅客与房东财产安全；
4. 仅在核验通过后开放蓝牙开锁等服务，做到“身份不明不提供服务”。

## 2. 产品逻辑

### 2.1 具体什么功能会要求用户进行授权；如同时申请多个字段，请明确不同功能需要的不同用户信息

**触发授权的功能：**  
进行中订单详情页，用户点击「实名认证」。

该功能对应法定义务中的“住宿身份查验与实名登记”，是开放后续自助入住服务前的必要前置环节。

**字段与用途对应关系：**

| 申请字段 | 对应功能 | 法律/业务用途 |
|---|---|---|
| 姓名 | 入住实名认证、住宿登记 | 对应《旅馆业治安管理办法》及《治安管理处罚法》要求登记的“姓名”信息 |
| 身份证号 | 入住实名认证、身份查验 | 对应“有效身份证件种类和号码”查验与登记要求，用于确认真实身份 |
| 手机号 | 入住实名认证、三要素一致性核验与联系确认 | 用于完成支付宝实名三要素一致性核验，并作为入住联系方式 |

说明：上述字段均服务于同一核心功能「入住实名认证 / 住宿身份查验」，不申请与该功能无关的信息；核验通过后，才开放「蓝牙开锁」等服务能力。

### 2.2 用户授权后提供给用户的服务是什么

用户同意授权并完成实名三要素核验后，小程序提供以下服务：

1. 完成住宿实名登记所需的身份信息核验；
2. 订单状态由「未认证」更新为「已认证」；
3. 在核验通过的前提下，向用户开放智能门锁「蓝牙开锁」等自助入住服务；
4. 展示与入住直接相关的必要信息，保障旅客顺利、安全入住。

即：授权并核验通过后，用户获得的是**合法合规的自助入住与开锁服务**，而不是与住宿无关的其他服务。

### 2.3 如果用户拒绝，那么应用是否会提供给用户自行输入信息的功能；如果不允许用户自行输入，原因是什么

**会提供自行输入信息的功能，但不会在身份未核验通过前提供住宿开锁服务。**

具体处理：

1. 用户拒绝支付宝授权后，不强制反复弹窗；
2. 允许用户手动填写姓名、身份证号、手机号，以便继续完成身份信息提交与核验；
3. 在身份核验未通过前，**不开放蓝牙开锁、不向用户提供完整门锁权限**；
4. 原因：根据《反恐怖主义法》第二十一条，对身份不明或者拒绝身份查验的，不得提供服务。蓝牙开锁属于住宿服务中的关键放行能力，必须在身份查验通过后方可提供；
5. 同时，该处理也符合《治安管理处罚法》第六十七条关于不得为身份不明、拒绝登记身份信息的人提供住宿服务的要求。

因此：  
- **拒绝授权 ≠ 不能填写信息**（可手动录入）；  
- **拒绝核验 / 核验未通过 = 不能获得开锁等住宿服务**（依法不得提供）。

## 可直接粘贴到申请表的精简版

**1. 业务背景和理由**  
久窝朋赞会支付宝小程序用于民宿等住宿业态旅客自助入住。依据《旅馆业治安管理办法》第六条，旅馆接待旅客住宿必须登记，并应查验旅客身份证件、如实登记；依据《治安管理处罚法》第六十七条，不按规定登记住宿人员姓名、有效身份证件信息，或为身份不明、拒绝登记身份信息的人提供住宿服务，将依法处罚；依据《反恐怖主义法》第二十一条及第八十六条，住宿业务经营者应当对客户身份进行查验，对身份不明或拒绝身份查验的不得提供服务，违者可处高额罚款。因此，申请支付宝实名三要素（姓名、身份证号、手机号）是落实住宿实名查验义务、防范向未核验身份人员开放蓝牙开锁等服务所必需，而非营销用途。

**2.1 授权功能与字段**  
用户在进行中订单点击「实名认证」时发起授权。姓名用于住宿登记中的姓名登记；身份证号用于有效身份证件查验与登记；手机号用于三要素一致性核验及入住联系。上述字段均服务于同一功能「入住实名认证/住宿身份查验」，核验通过后方可开放蓝牙开锁。

**2.2 授权后服务**  
用户授权并核验通过后，完成住宿实名认证，订单状态变更为「已认证」，并可使用蓝牙开锁等自助入住服务。

**2.3 拒绝后处理**  
用户拒绝授权后，应用允许手动填写姓名、身份证号、手机号，且不强制反复弹窗；但在身份核验未通过前，不开放蓝牙开锁等住宿服务。原因是《反恐怖主义法》明确要求：对身份不明或拒绝身份查验的，不得提供服务；同时符合《治安管理处罚法》关于不得为身份不明人员提供住宿服务的规定。
