# 久窝支付宝小程序实名/实人认证 · 使用背景与能力说明

## 一、使用背景

久窝 C 端支付宝小程序（久窝朋赞会，AppID：`2021006157657093`）服务于民宿/酒店旅客自助入住。

旅客通过短信或订单入口打开「入住指南」后，需要完成本人身份核验，系统才会展示：

- 详细门牌/导航说明
- 门锁密码
- 蓝牙开锁能力
- 其他私密入住信息

该能力用于满足旅馆业住宿实名登记要求，并保障门锁/客控等敏感信息只对本人开放。

## 二、申请能力

### 方案二：用户实名三要素验证

核验字段：

- 姓名
- 身份证号
- 手机号

使用时机：

- 旅客点击「去认证」
- 提交入住实名信息
- 展示门锁密码前

申请材料：

- 本 DEMO 包（含授权前/授权弹窗/同意后/拒绝后）
- 本使用背景说明

### 方案三：用户刷脸实人认证后验证

在三要素通过后，进一步确认本人操作。

适用：

- 门店开启严格实人入住
- 未成年人/重点风控订单
- 需要确认「证件信息提交人」即现场操作人

申请材料：

- 三要素申请成功证明
- 本 DEMO 包中的刷脸页流程
- 相关机构管理要求文件（营业执照、住宿业务说明、隐私政策、身份信息处理说明等）

## 四、拒绝授权处理（符合支付宝规范）

- 拒绝后展示「身份核验未完成」说明页
- **不立即、不连续、不强制重复弹窗**
- 仅当用户再次点击「重新发起核验」时重新调起授权
- 提供「联系房东」线下核验替代路径
- 拒绝期间不展示门锁密码等敏感信息

## 五、数据使用与安全

使用目的仅限：

- 住宿实名登记
- 入住人身份核验
- 门锁密码/自助入住信息展示前安全校验
- 必要审计留痕

安全措施：

- 前端不展示完整身份证号
- 日志/审计脱敏
- 身份影像走私有存储
- 不用于营销或其他无关用途
