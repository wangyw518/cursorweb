## 流程图内容（对应图二/图三）

1. **授权前**：进行中订单，状态「未认证」，点击「实名认证」
2. **授权弹窗**：申请姓名、身份证号、手机号
3. **同意**：带入实名信息办理核验
4. **拒绝**：仅可手动录入
5. **核验通过后**：订单变为「已认证」，可「蓝牙开锁」
