---

## DEMO 覆盖的审核场景

按支付宝要求，本 DEMO 覆盖：

1. **授权前上级场景**：入住指南页，提示需实名认证后才可查看门锁密码
2. **授权弹窗页面**：申请姓名、身份证号、手机号、实名核验结果
3. **同意授权后下级场景**：核验通过，展示完整入住指南与门锁密码
4. **拒绝授权后下级场景**：核验未完成，不强制反复弹窗，仅用户主动重试

补充：

5. **刷脸实人认证页**（方案三）

---

## 使用方法

1. 解压本包
2. 用 Chrome / Edge / Safari 打开 `demo/index.html`
3. 左侧可一键切换 4 个必审场景
4. 也可在右侧手机界面内点击按钮完整走通流程
