# 双机冒烟（P0 放行硬门槛）

**双机冒烟不过，不许喊用户验收。** 昵称 / 观战 / 音乐 / 3D 等好友房改动合入前，必须先过本清单。

两边同一 `room.roomApiBase`（或同一 `cloudEnv`）。局域网示例：`node taiqiu/dev/room-server.js 8788`，客户端填 `http://<电脑局域网IP>:8788`，不要填 `127.0.0.1`。

## 开屏 / 导航

- [ ] 冷启动开屏三入口并列可见：**人机对战** / **练习模式** / **好友对局**
- [ ] 点空白台面不进人机
- [ ] 任一模式底栏 **返回大厅** 立刻回开屏三入口

## 人机 / 练习

- [ ] 人机：20s 倒计时；轮到 AI 时显示 **AI出杆中** 并自动出杆
- [ ] 练习：无倒计时、无对方筹码、不换人
- [ ] 穿库 / 出界：该球离桌，HUD 目标改号（不再挂已出界球）
- [ ] 贴边仍能拉到 **满** 蓄力
- [ ] 远球瞄准虚线够长，能指到目标
- [ ] **音乐** 在安全区（底栏左侧），真机可点，不被微信胶囊挡住
- [ ] **瞄准3D** 已隐藏；不要出现可点但无效的按钮

## 好友双机

- [ ] 冷启动带 `roomId`（分享卡片 / `onLaunch`）直接进房，不先落人机
- [ ] 顶栏是真昵称（微信 nick / 可配置 `displayName`），自己一侧标 **你** 或高亮；禁止只显示「房主 / 好友」
- [ ] Aim：对端虚线连续（插值，同步 ≤100ms），不要一跳一跳
- [ ] Shot：对端能看到击球反馈和 **rolling 滚球**，禁止只跳最终静帧
- [ ] 双方星币分列（主机 / 客机各记各的）
- [ ] join 失败有可见 toast（房间无效 / 已满 / 已结束 / 服务器连不上）+ **重新加入**

node taiqiu/test/m0.test.js
node taiqiu/test/m1.test.js
node taiqiu/test/invite-join.test.js
