# 05 · 表设计（MBS 自有库）

> 范围：**仅 MBS 自有库**（用户/交易/平台会员/门店会员/钱包-储值-随心住-积分-券/AI 行程/内容/触达/横切）。
> 供给/履约/门锁（房源/房态/价格/指南/占房/booking/实名/公安）**不建表**，走 PMS 真源，MBS 以 `pms_booking_id` 等指针关联。
> DB：MySQL 8 / InnoDB。规范：
> - 主键 `BIGINT UNSIGNED AUTO_INCREMENT`；对外号(`*_no`/`uid`)走二级唯一索引。
> - `ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_0900_ai_ci`；尽量 `NOT NULL`；时间 `DATETIME`。
> - 状态 `TINYINT`+注释常量（见 `04` 状态机）；金额一律**分**（整数）。
> - 敏感字段加密：密文 `VARBINARY` + HMAC 盲索引 `CHAR(64)`。
> - **资金/权益台账（成长值/积分/储值/随心住核销）只增不改**，余额单独落表，便于对账。
> - 门店维度隔离：门店会员/储值/门店积分/随心住均带 `store_id`（关联 PMS 门店 `property_id`）。
> - 表名统一 `c_` 前缀。未显式写处默认含：
> ```sql
> created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
> updated_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
> ```

CREATE TABLE c_user (
  id BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  uid CHAR(20) NOT NULL COMMENT '对外用户号',
  mobile_cipher VARBINARY(256) NULL COMMENT '手机号密文',
  mobile_hash CHAR(64) NULL COMMENT '手机号HMAC盲索引',
  nickname VARCHAR(64) NOT NULL DEFAULT '',
  avatar_url VARCHAR(512) NOT NULL DEFAULT '',
  gender TINYINT NOT NULL DEFAULT 0 COMMENT '0未知1男2女',
  birthday DATE NULL,
  status TINYINT NOT NULL DEFAULT 1 COMMENT '1正常0停用9注销',
  register_channel VARCHAR(16) NOT NULL DEFAULT '' COMMENT 'wxmp/alipay/h5',
  companion_days INT UNSIGNED NOT NULL DEFAULT 0 COMMENT '已陪伴天数(展示)',
  last_login_at DATETIME NULL,
  created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (id), UNIQUE KEY uk_uid (uid), UNIQUE KEY uk_mobile_hash (mobile_hash),
  KEY idx_status_created (status, created_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_0900_ai_ci COMMENT='C端用户';

CREATE TABLE c_user_oauth (

## 十三、设计要点回顾

1. **交易域全在 MBS**（`c_order` 系列 + 支付/退款），`pms_booking_id` 单指针连 PMS 履约域——回答"用户产生数据尽量全放 C 端"。
2. **双级会员皆 MBS 真源**：平台会员(`c_member`+成长值台账)、门店会员(`c_store_member`)；**晚数/成长来自 PMS 入住完成事件**（`c_inbox_event` 幂等）。
3. **预付资金严谨落台账**：门店储值(`c_store_wallet`+ledger)、随心住(`c_flexi_pass`+`c_flexi_redeem`)、积分(`c_point_*`)、礼品卡——**余额表 + 只增不改流水**，可对账；发票/退款按合规。
4. **随心住核销与占房事务一致**：`c_flexi_redeem.uk_order` 幂等 + outbox 补偿，先 PMS 占房再扣券。
5. **门店维度隔离**：门店会员/储值/门店积分/随心住均带 `store_id`，各店独立不通用。
6. **定价组合在 MBS**：`c_order` 拆 `platform_discount/store_discount/coupon_discount/flexi_deduct_nights/wallet_amount`，房价基线来自 PMS 冻结快照。
7. **敏感与合规**：证件号/手机号密文+盲索引；证件照原文只在 PMS 私有空间。
8. **可扩展**：热表 PK 单调自增，台账可按时间分区，未来按 `user_id` 分片迁 Vitess/PlanetScale。
