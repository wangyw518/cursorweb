# 六款试玩厅

一次试玩 6 个微信小游戏原型，对比哪个更好玩：

1. **最后一格** — 坑人占格 + 隐形陷阱  
2. **红包会跑** — 点早空包 / 点晚被截  
3. **电梯困局** — 超载拖人，社死结局  
4. **一句搞定** — 四字回击打血条  
5. **倒着通关** — 从终点退回起点  
6. **谁在说谎** — 1.2 秒点穿骗子  

## 本地体验

```bash
npm install
npm run dev
```

手机与电脑浏览器都可。大厅点卡片进入；左上角回大厅。

```bash
npm run build
npm run preview
```
